# Documento de Visão

## 1. Problema e Oportunidade
* **O Problema**: O hospital possui dados bem estruturados e abrangentes, porém não estão agregados de forma a gerar o valor e visão necessários para uma melhor operação logística.
* **Impacto**: A dor atual dificulta a visualização de dados que, por si sós, não geram nenhum valor sobre o fluxo operacional dos eventos dos pacientes.
* **Solução Proposta**: O sistema proposto agrupa a jornada do paciente em etapas e filtra os indicadores gerados, por especialidade, de forma a melhorar a visão geral sobre os dados, além disso organiza-os de forma cronológica e rastreável.

## 2. Partes Interessadas (Stakeholders)
* **Profissionais de Saúde**
* **Gestão Hospitalar**

## 3. Escopo do Produto
 Funcionalidades principais e limites do projeto.
* **Organização em Dashboard de módulos do paciente**
* **Projeto se limita à fonte de verdade (AGHU)**
* **Linha do tempo do paciente no HC**

## 4. Metas e Objetivos de Negócio
 Metas mensuráveis de melhoria hospitalar.
* **Melhor aproveitamento de recursos em geral**
* **Maior extração de significância pelos dados de eventos**
* **Visualização fácil de indicadores de cada etapa da jornada do paciente**
